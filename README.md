📌 Overview

The Food Recipe Generator (CLI) is a Python-based application that generates cooking recipes with dynamic ingredient scaling based on number of servings.

It provides a simple interactive menu system to explore different food categories and get step-by-step cooking instructions instantly.

✨ Features
🍽️ Multiple food categories
📏 Automatic ingredient scaling
🧑‍🍳 Step-by-step recipe instructions
🖥️ Interactive CLI menu system
🌶️ Wide variety of Indian recipes
🎨 Colored terminal output using simple_colors

🧠 How It Works
Run Program → Choose Category → Select Recipe → Enter People Count → Get Recipe

Output Includes:
Scaled ingredients
Cooking steps
Clean structured recipe format
